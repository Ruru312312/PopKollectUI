PopKollect: A Funko Pop Collection Tracker

Overview:
  A desktop application that helps users track and manage their Funko Pop collection, with real-time market price data.

Features:
  Add, edit, and manage Funko Pop collection entries
  Entries can be created using a barcode or name
  User-friendly interface (UI) for collection tracking
  Fetch and analyze market listings using eBay REST API
  Compute average market price using retrieved listings data
  Store and retrieve market price data using Firebase
  Local data storage using SQLite for offline access

Tech Stack:
  Python (backend processing)
  Javascript (UI)
  Firebase (Cloud Integration)
  SQLite (Local Database)
  eBay REST API
